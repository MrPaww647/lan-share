# lan-share v0.1.12

Простая программа для быстрой передачи файлов между двумя ПК в одной локальной сети.

## Установка

Скачайте `lan-share Setup 0.1.12.exe` со страницы релиза и запустите установщик.

## Передача файлов

1. Запустите lan-share на обоих ПК, подключённых к одной локальной сети.
2. На первом ПК скопируйте адрес комнаты и шестизначный код.
3. На втором ПК введите адрес и код в блоке «Подключиться к другому ПК».

Вместо приложения на втором устройстве можно открыть адрес комнаты в браузере и ввести код на странице. При запросе Windows разрешите доступ в частных сетях. Полученные файлы хранятся в каталоге данных приложения.

Приложение использует код подключения; максимальный размер одного файла — 10 ГБ. Закройте приложение, когда обмен завершён.

## Сборка из исходников

Требуется Node.js LTS. Выполните `npm install`, затем `npm start` для запуска или `npm run dist` для сборки установщика Windows x64. Установщик появится в папке `artifacts`.
